Attack range mask generation notes

Purpose:
- Keep the attack range overlay visually locked to the original BattleGrid_Full_Image2 panel perspective.
- Avoid rectangular UI overlays or independently warped panel sprites that can drift from the source panel corners.

Current implementation:
- BattleScene uses RangeRows/AttackRangeRow_R0.png through AttackRangeRow_R2.png.
- RangePanels and RangePanelsAligned also contain one full-size transparent panel mask per cell.
- These files are full-size transparent overlays at 1672x941, matching BattleGrid_Full_Image2 exactly.
- Alpha is nonzero only on panel top surfaces.
- Non-range panels, side walls, the board base, and frame glow remain transparent, so the original board image is not overwritten.

Mask method:
- Panel footprints are generated by GeneratedRangePanelSource/generate_top_surface_range_masks.py.
- Each cell has its own top-surface bounds in BattleGrid_Full_Image2 pixel space.
- The last column uses its own panel top-surface right edge and never falls back to boardRight or texture.width.
- A polygon mask is built from the bright top-surface pixel hull inside each cell's bounds.
- The fill is a low-alpha gold layer clipped to the resulting panel top-surface polygon.
- Bright gold edge/circuit accents are derived from the original BattleGrid_Full_Image2 pixels inside that top-surface mask.
- This matches the strategy/tactics RPG convention of tinting the existing tile footprint instead of placing a separate rectangular effect.
